## 🌟 Fitur Utama Web App

1. **Hero Section & Identitas Brand Eksklusif**:
   - Menampilkan visual produk asli botol spray 500 ml dan foto lifestyle buah segar terlindungi.
   - Tagline resmi, badge *100% Food Grade*, dan tombol CTA responsif.
2. **UVP (Unique Value Proposition)**:
   - 100% Food Grade & Edible (bebas bahan kimia sintetis).
   - Memperpanjang umur simpan 7–14 hari tanpa *cold chain* (suhu ruang).
   - Berbasis ekonomi sirkular ramah lingkungan (limbah kulit buah & cangkang hasil laut).
   - Praktis & sangat ekonomis (hanya ~Rp1.750 per kg buah).
3. **Simulasi Interaktif Komparasi Kesegaran (Before vs After)**:
   - Pilih komoditas: **Mangga Arumanis**, **Tomat Sayur/Cherry**, **Cabai Rawit Merah**, **Pisang Cavendish**.
   - Slider timeline penyimpanan: **Hari 1**, **Hari 5**, **Hari 10**, dan **Hari 14**.
   - Metrik komparasi real-time: susut bobot (%), tingkat kekerasan buah, infeksi jamur, dan nilai jual pasar.
   - Interactive Before/After image slider dengan handle geser ↔.
4. **Kalkulator Penghematan Usaha & Analisis ROI**:
   - Slider volume panen mingguan (50 kg – 3.000 kg).
   - Slider harga komoditas (Rp10.000 – Rp80.000 / kg).
   - Slider tingkat susut busuk normal (5% – 35%).
   - Menghitung secara instan: potensi kerugian diselamatkan, biaya pemakaian PectiShield™, tambahan laba bersih, dan persentase ROI.
5. **Katalog Produk & Sistem Pemesanan Lengkap**:
   - **Kemasan Botol Trigger Spray 500 ml (Siap Pakai)**: Rp35.000 / botol.
   - **Kemasan Jerigen 5 Liter (B2B & Kemitraan)**: Rp275.000 / jerigen.
   - **Paket Sampel Trial Gratis 100 ml**: Rp0 (khusus pengujian mandiri petani/pelaku usaha).
6. **Keranjang Belanja Dinamis & Integrasi Pemesanan WhatsApp Otomatis**:
   - Slide-over drawer keranjang belanja lengkap dengan penyesuaian kuantitas (+/-) dan subtotal.
   - Modal checkout otomatis menyusun format pesan WhatsApp terstandar ke nomor resmi: **+62 877-7742-1044**.
7. **Formulir Pengajuan Sampel Gratis**:
   - Modal interaktif untuk kelompok tani dan pelaku usaha meminta sampel uji coba 100 ml.
8. **Panduan Formula & 4 Bahan Alami**:
   - Ekstrak Pektin Kulit Buah, Kitosan (Chitosan) Cangkang Udang/Kepiting, Gliserol Nabati Food Grade, dan Asam Askorbat (Vit C).
9. **Panduan Praktis Cara Pakai 3 Langkah** & **Dokumentasi Foto Asli**.

## 🚀 Cara Menjalankan Aplikasi

### Opsi 1: Menjalankan dengan Server Python (Rekomendasi)
Buka terminal / PowerShell di folder ini, lalu jalankan:
```bash
python server.py
```
atau klik dua kali file:
```
start.bat
```
Buka browser di alamat: [http://localhost:8000](http://localhost:8000)

### Opsi 2: Langsung Buka File HTML
Buka file `index.html` langsung di browser Anda (Google Chrome, Microsoft Edge, Firefox, Safari).
